# 寸光阴

**开个 App 还得先找「跳过」？这回让手机自己找。** 😋

寸光阴是一款 Android 开屏广告跳过工具。开启无障碍服务后，它会尝试识别并点击开屏广告的「跳过」按钮，也能关闭部分应用内广告弹窗。这个仓库提供签名 APK、版本说明和问题反馈入口。

## 安装与使用

1. 在最新版本的 **Assets** 中下载 APK。使用寸光阴旧版的用户可以直接覆盖安装。
2. 打开寸光阴，按提示在 Android 系统设置中开启无障碍服务。
3. 回到桌面打开目标应用。可在「应用」页按应用设置处理范围，在「记录」页查看本机点击和复核结果。

## 功能

- **开屏跳过与弹窗关闭**。识别合在一起或分开显示的「跳过」与倒计时。控件点击无效时，对高置信度目标尝试手势补点。
- **点击复核**。记录点击动作及可核实的按钮状态。按钮离开画面也可能来自倒计时自然结束。
- **诊断留痕**。怀疑开屏广告漏跳，或点击后原按钮仍显示时，可在「记录」页开启诊断并复制脱敏摘要。功能默认关闭，最多在内存中保留 20 条，进程退出后清空。
- **隐藏最近任务**。在「总览 → 快捷操作」开启后，寸光阴卡片会从系统最近任务中隐藏，仍可从桌面打开。开启前台保活时，Android 会显示状态通知。
- **自定义提示**。可开关跳过短提示和修改保活通知文案。默认的保活通知正文为「一寸光阴一寸金」。

## 技术实现

项目以 Java 编写，使用 Android 原生 `AccessibilityService`、`AccessibilityNodeInfo` 和 `GestureDescription`。

1. **获取候选**。在应用切换和开屏窗口变化时补查可访问控件。结合控件树遍历与按文字、资源 ID 查询，定位较深层级中的按钮。
2. **核对目标**。结合倒计时、位置、父子控件关系、广告提示和活动窗口。分离式倒计时需指向同一个小型可点击控件，遇到同组还有其他可点击操作时放弃匹配。
3. **执行与复核**。优先发出控件点击，符合条件时补点。随后复核原按钮是否还显示，并将结果写入本机记录。

## 测试与支持范围

- APK 的最低系统版本为 Android 7.0。1.0.7 在 Android 13–17 上运行了 **40 项组件测试**，包括分离式倒计时、数字徽标、同组其他按钮、旧记录兼容和后台设置。
- 1.0.8 在 Android 13–17 的 **46 项组件测试**通过，新增了漏跳时机、点击复核、摘要脱敏、清空后防回写和无障碍读取次数的对照。
- 此前的 Android 17 模拟器回归覆盖了深层按钮、手势补点、验证码页面误点保护，以及隐藏最近任务后继续跳过测试广告。1.0.7 的实际点按对照因模拟器启动超时尚未完成。
- 学习通、知乎、慧生活798已有用户提供的真机点击命中记录。应用版本、广告样式和厂商系统会影响实际表现。
- 纯画面广告、无可访问关闭控件的广告和带「应用详情」浮层的双层广告可能需要手动处理。后台运行时间受 Android 和厂商系统策略影响。

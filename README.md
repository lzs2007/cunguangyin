# 寸光阴

**开个 App 还得先找「跳过」？这回让手机自己找。** 😋

为了省开屏那几秒，我做了个安卓小工具，叫**寸光阴**。打开 App 时，它会尝试识别并点击开屏广告的「跳过」按钮，也能关闭部分应用内广告弹窗。学习通、知乎、慧生活798已有真机命中记录，实际效果会随应用版本和广告样式变化。

## 下载与使用

1. 在版本页面的 **Assets** 中下载 APK。已安装旧版可直接覆盖更新。[下载寸光阴](https://github.com/lzs2007/cunguangyin/releases/latest)
2. 打开寸光阴，按提示在系统设置中开启无障碍服务。
3. 回到桌面打开一个 App，即可试用自动跳过。可在寸光阴的「应用」页按应用设置处理范围。

## 有哪些功能

- **开屏跳过与弹窗关闭**。结合按钮文字、倒计时、控件 ID 和窗口信息判断。控件点击无效时，可对高置信度目标尝试手势补点。
- **点击记录**。在本机查看点击和可核实的按钮状态。按钮消失也可能是倒计时自然结束。
- **隐藏最近任务**。在「总览 → 快捷操作」开启后，寸光阴卡片会从系统最近任务中隐藏，仍可从桌面打开。开启前台保活时，Android 会显示状态通知。
- **自定义提示**。可开关跳过短提示、修改后台通知文案。「一寸光阴一寸金」是默认保活通知正文。

寸光阴使用 Android 无障碍服务识别和操作前台界面。纯画面广告、未提供关闭按钮的内嵌广告可能需要手动处理。后台运行时间受系统策略影响。
